repository and isolated testing. This supersedes the earlier private-only choice.
Repository: https://github.com/joystuu/slinky-isolated-review

Manual-only windows-2022 standard GitHub-hosted VM; public-repository guard;
20-minute job timeout; read-only checkout token with no persisted credentials;
no personal credentials; no Actions artifact/cache uploads. Do not run the client
on the user's PC or move to paid runners. Source and CI logs are public.

All 312 original source inputs are SHA256-checked before build-generated files
are created. Three ASM 9.6 dependencies already independently verified against
upstream are stored under ci/vendor with their BSD license. Other dependencies
download from the original pinned Mojang/Minecraft URLs and are hash-checked.
No supplied client EXE/DLL or proprietary game JAR is published in this repo.

Tests rebuild Java payloads, native DLL and launcher in the remote VM; record
artifact hashes; monitor the launcher without a target using signed Microsoft
Process Monitor; then provision official Minecraft 1.8.9 for an offline startup
and injection attempt. Minecraft graphics compatibility is determined at runtime.
Pinned Mesa Windows 26.2.5 software OpenGL is installed beside the disposable
JDK executable because the default virtual display exposes only OpenGL 1.1.
Outbound networking is blocked per launcher/JVM program. This is not a global
network-denial guarantee. No personal login or public game server is used.

Filtered process-tree traces are gzip/base64 encoded into ordinary job logs to
preserve evidence without Actions artifact storage. Raw PML/full-system trace
exists only during the ephemeral job. Process Monitor is not comprehensive EDR;
activity through unrelated processes, delayed behavior, and unexercised features
may escape this bounded observation. See individual run logs for actual coverage.
Passing tests cannot establish 100 percent safety or safe use on a personal PC.
